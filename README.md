**To whoever may stumble upon this fork:**
This is my attempt at reconciling Lithostitched's custom DFs and biome injectors with C2ME's OpenCL-accelerated worldgen (i.e., the alphas found on the RelativityMC discord).

The project is _technically_ buildable in its current state, but the dev environment is a pain to set up and will be until ishland releases OCL builds on Modrinth. 
If you want to set this up, you'll need the baseline C2ME dependencies (see the repo), all listed programs on the OCL discord info channel, and CMake + GNU Make. 
Also, you'll need to download the source .gitarchive for the latest alpha, set that up, and publish that to your local maven. I'm still probably forgetting something, to be honest.

Once Modrinth builds are published, this process will be much simpler.
